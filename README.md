# DSA Practice

A structured collection of Data Structures and Algorithms problems solved in **C and C++** for improving problem-solving skills and preparing for technical interviews.

## 📚 Topics

This repository covers DSA topics progressively:

- Mathematics
- Arrays
- Strings
- Sorting
- Binary Search
- Recursion
- Linked List
- Stack
- Queue
- Hashing
- Trees
- Heaps
- Graphs
- Greedy Algorithms
- Dynamic Programming
